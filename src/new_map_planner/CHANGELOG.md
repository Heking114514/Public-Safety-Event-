# Changelog

## Unreleased

- 2026-10-10：规划服务按 `activate` 请求门控可执行 `navigation_path` 发布；预览仍发布
  `route_plan` 和 `arena_path`，但不发布普通导航路径；恢复专用路线也不会进入该通道。
- 2026-10-10：关闭 `publish_shunt_markers` 时启动直接失败，避免返回控制器无法识别转弯的成功路线。
- 2026-10-10：移除从未参与搜索的 `reverse_cost`、`u_turn_threshold` 配置；覆盖搜索删除无效的转弯代价计算，目标路线的 `turn_cost` 保持有效。

- 2026-10-10：起点转弯 `START_ALIGN` 现在携带与车辆来向匹配的真实入边车道 ID；若地图没有
  可恢复的来向道路则拒绝生成该转弯，避免总控在恢复时使用伪造上下文。
- 2026-10-10：补齐恢复起点契约。`PlanRoute` 请求新增正常、转弯恢复和障碍恢复三种显式
  起点模式，以及恢复锚点、来向车道和倒车授权；转弯恢复只生成一段沿指定来路退离的
  `REVERSE` 路线，并继续执行现有 footprint、道路边界和动态障碍检查。
- 恢复结果新增 `recovery_only` 标记和独立失败状态。障碍恢复仍由控制器历史轨迹负责；
  恢复路线不会发布到普通导航 Path，避免现有控制链将其误当作前进路线。
- 恢复倒车段的 Path 元数据标记固定在段起点，导航器进入该段前即可选择闭环倒车，避免先
  前进一个控制周期再切换方向。
- 规划器转弯配置从中央车辆配置读取 `base_link_offset_y_m`，补齐与控制器安全模型的物理参数
  契约；新增正常模式兼容、恢复上下文、锚点、前后障碍和恢复所有权回归测试。
- 起点转弯 waypoint 的 yaw 固定输出离散入口道路方向，避免将车辆实际到达航向残差传给导航器
  的路口几何和 footprint 检查；增加入口航向残差回归测试。
- 规划器 UI 车辆图标改为读取共享 `vehicle_physical.yaml` 的车长和车宽，和规划器安全计算保持一致。
- 覆盖规划由逐段最近道路贪心改为包含节点、航向、普通节点计数、入边和覆盖集合的完整
  状态搜索；部分路线只允许停在仍可前向续规划且按需可回家的合法图节点。
- 正常目标与覆盖规划不再生成跨道路倒车段；需要倒退脱困时明确返回无前向可行路线，
  由外部恢复状态沿真实历史轨迹处理。原地旋转、道路内掉头和非恢复长距离倒车仍被禁止。
- 新增 ROS 无关的 `navigation_safety` 几何库；规划器的 footprint、障碍相交和轨迹扫掠改用
  共享实现并删除规划器中的旧 footprint/SAT 副本，保留原地图、动态障碍和各路径类别余量。
- 转弯扫掠验证与实车控制统一使用路口状态格：动作线速度为 ±0.035 m/s，允许在已确认路口
  内多段前进/倒车，动作集合不包含原地旋转。
- 目标点规划在道路被动态障碍封住时允许从路口沿当前道路倒车接入下一段；倒车段保持
  车体原有偏航，不生成原地 180 度掉头。路线编译器只接受从图节点开始的反向段，并新增
  实际恢复姿态回归测试。

## 2026-10-08

- 为固定物理点配置 `s1`–`s12` 超节点 ID，并让每个路线航点携带对应 ID；导航器据此等待
  RFID 确认，防止普通路口和超节点混淆。
- RFID 重定位后距图节点不超过 5 mm 时直接捕获为该节点，保留一条无需方向校验的微小
  连续段，避免数十微米残差生成随机吸附航向并拒绝下一阶段规划。
- 删除 61 点紧转姿态表；规划器启动时运行导航器共享的闭环转弯模型生成参考扫掠，实车
  到点后按实时位姿连续闭环控制。移除不参与车身几何的轮距依赖。
- 规划器转弯余量调整为与执行器相同的 2 mm；直行仍使用完整 15 mm 余量。
- 修复曾将转弯安全余量设为负值并按拓扑直接放行的问题；现在按 125 mm × 148.5 mm
  真实车身和 2 mm 余量连续扫掠，验证地图中所有 90 度转向。
- 规划器 UI 的驻停请求改走 `/navigation_mission/set_motion_hold`，驻停所有权按总控映射后
  的来源判断。
- 修复起点短距离吸附：吸附段保持实时车头航向，不再用起点到节点的斜线方向替换车体
  航向，避免顶部隧道边界出现毫米级假碰撞和后续恢复。
- 初始吸附段增加与当前航向一致性检查；需要倒车或横向接入时明确拒绝，交给任务层继续
  退到可执行历史锚点。

## 2026-10-07

- `layer1` now plans the next pending task point first, falling back to another
  reachable task only when that target has no legal route. Graph search tracks
  arrival heading and the number of consecutive ordinary junctions; the count
  is returned with each route and carried into the next planning request.
- 部分覆盖路线必须至少完成一条当前阶段要求的道路；仅执行厘米级起点吸附、所有阶段
  目标仍 deferred 的零进展路线不再发布。
- 新增 `z=0.002` 反向进站转弯语义；规划器与控制器共用状态格核心，连续验证“探入
  边缘道路、倒车退回路口、转入下一道路”的完整车身扫掠。

## 2026-10-06

- 路口附近的起点吸附段若需要先倒车或横移，不再伪装成普通前进 `Path` 并返回成功；
  规划器明确拒绝当前恢复姿态，让任务层继续退到可执行的更早锚点。

## 0.2.0 - 2026-10-05

- 新增 `layer1` 任务点、`layer2` 隧道和 `layer3` 普通道路补漏回程三阶段规划策略。
- 新增独立 `StagedMission` 任务状态模块，路线只有在 ACK 和 `GOAL_REACHED` 后才提交；
  成功段自动衔接，故障段暂停等待操作员恢复。
- 实车 UI 增加阶段、剩余任务/隧道/道路状态和“继续巡视”入口。
- 实车 UI 从任务状态拥有者降级为操作台，完整巡视通过
  `navigation_mission_manager` 命令和状态接口运行，关闭 UI 不影响后台任务。
- loopback 默认执行三阶段全链路，并从每阶段最新真值位姿续规划。
- 三阶段闭环已用正式 `waypoint_navigator` 跑到 `mission_complete:stages=3`，三段长度分别
  为 `13.70 m`、`9.04 m`、`15.74 m`，最终回程位置误差约 `38 mm`。

## 0.1.0 - 2026-10-04

- 新增道路图主规划、航向状态搜索和独立车身碰撞验证层。
- 新增显式 `Maneuver`、`RoutePlan` 与 `PlanRoute` ROS 接口。
- 正式 12 点任务使用精确集合搜索；道路覆盖保留延期结果。
- 动态障碍改为请求级多边形验证，不重建静态栅格。
- 新增仅面向实车的 Tk 操作界面、路线 ACK 监控和导航驻停。
- 将前方 Bool/Range 观测按导航恢复结果提升为请求级动态障碍，并在 UI 显示和清除。
