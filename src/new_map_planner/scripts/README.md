# 独立路径规划仿真

按《智能避障方案前瞻》做拓扑路径规划。默认启动本机交互页面：开始导航前点选三个障碍位置，开始后锁定封边配置并显示路线。使用 Python 3 和 PyYAML，不需要启动 ROS 或编译工程。

## 交互启动

```bash
cd /home/hjh/zhongzhouyanda/worktrees/forward-route-sim-20261016
python3 src/new_map_planner/scripts/simulate_route.py
```

脚本会打开本机浏览器，也会在终端显示地址。若浏览器没有自动打开，可将该地址粘贴到浏览器。点击地图上三条不同的绿色普通道路设置障碍，再点击“开始导航并锁定”。顶部三条道路和四条隧道不能选择。开始时只接受恰好三个不同的合法道路；同一边的两个方向是同一物理边。需要传入预设位置时，可追加三个节点对：

```bash
python3 src/new_map_planner/scripts/simulate_route.py \
  --blocked 1,2 6,10 11,12 \
  --output /home/hjh/forward_route_sim/route.html
```

`--blocked` 会预选这些边，但仍可在开始前更改。导航成功开始后，页面和服务端都锁定本轮封边；暂停、回看、重放、重新加载都不会解锁。服务只监听 `127.0.0.1`；按 `Ctrl+C` 退出。`--no-open` 可关闭自动打开浏览器，`--port 0` 使用系统分配端口。

如只需生成静态路线、不进入交互布障流程，可用 `--static`：

```bash
python3 src/new_map_planner/scripts/simulate_route.py \
  --static --blocked 1,2 6,10 11,12 --no-open \
  --output /home/hjh/forward_route_sim/route.html
```

规划后生成 HTML、SVG 和 JSON。交互服务运行期间，网页下载链接可取回 SVG 和 JSON。规划默认限时 5 秒、最多扩展 200000 个状态；可用 `--timeout` 和 `--max-states` 调整。找到完整路线或仍能返航的部分路线都会进入已锁定的路线播放页；只有没有任务进展或无法返航时才报告无可执行路线，障碍仍可在开始前修改。

## 图怎么看

- 每条物理边的每次通行都用单独的平行线、运动方向箭头、步骤号和通行次数标记。
- 第一次蓝色、第二次橙色、第三次紫色、第四次青色；重复边另有金色底带和 `×N` 徽章。
- 所有路线段均为前进运动；路线箭头显示运动方向，随车黑色箭头显示车头朝向。
- 封边画红叉但保留端点；黄色节点是 RFID，绿色编号和 RFID 编号分别显示。
- RFID—RFID 共线直行例外的每一步均有显眼文字，定位计数逐边展示。
- 路线播放支持暂停、逐步、拖动进度、倍速和点击步骤跳转。

## 规划规则

完整路线会经过全部 12 个 RFID、通过全部 4 条隧道并返回起点。障碍导致目标无法全部兼顾时，按 RFID 优先降级：先舍弃无法合法完成的隧道，再舍弃无法合法完成的 RFID；只要已有任务进展且能够返航，就保留并启动部分巡航路线，不能因为少数目标失败而放弃整个巡航。优化在相同 RFID 数和隧道数下尽可能增加不同物理边、减少重复通行，再比较距离和转弯代价。搜索在时限或状态上限内保留当前最佳返航候选，明确标注完整或部分结果，不把启发式候选宣称为全局最优。

每经过 RFID 停车定位 1 秒，首次还播报。正常情况下经过两个普通节点后必须到 RFID，不能继续经过第三个。唯一例外为完整畅通的共线 RFID—RFID 直行段：可在起端 RFID 执行合法转弯并对准长直路，之后保持同一方向、不在途中转弯换向，通过多个普通节点直到另一端 RFID；每个普通节点仍逐一计数，并且不能提前结束或离开该直线段。当前地图识别出的竖直长直段包括 `R1—绿2—绿6—绿10—绿14/R6` 和 `R12—绿3—绿7—绿11—绿15/R7`，可向两个方向通行；有一条边封闭就不能走整段例外。

车辆全程只前进，禁止倒车、倒车转向和原地掉头；转弯前在中心前 7 cm 的固定入口停车，再执行既定的前向特定转弯动作。封边双向禁止穿越，但两端节点和其他可用相邻道路仍保留。

地图共有 29 条物理边。顶部三条边和四条隧道不会放障；输入节点对必须对应地图中一条相邻的绿色普通道路。交互启动时可暂存零至三个障碍；必须选择恰好三个不同的合法物理边才能开始。

这是路径级拓扑仿真，7 cm 入口和车体扫掠仍需在真实车辆仿真中验证。脚本不发送车辆运动命令。
