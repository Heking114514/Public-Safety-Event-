# 变更记录

## 未发布

- 新增[避障恢复修复方案](../../OBSTACLE_RECOVERY_FIX.md)：明确允许朝障碍方向前进的双向姿态调整、出口评估与实际出口交接，以及利用现有仿真固定短场景定位问题的步骤。本次仅更新文档，尚未实施或验证新恢复逻辑。

- 接通 Contrast 避障验证入口 `obstacle_validation.launch.py`：正式任务总控独占规划和 loopback 检查点授权，仿真检测开启且静态碰撞保护保持开启；完成直路障碍的检测、刹停、倒退、动态障碍上报、碰撞校验重规划和后续路线恢复实跑。详细证据见 `OBSTACLE_VALIDATION_REPORT.md`。
- 修复总控规划请求未显式打开 `validate_geometry` 与 `online_geometry_validation` 的问题；此前动态多边形虽已传给规划器，但可能生成穿过障碍的路线。

- 完成 Contrast 单车三层闭环实跑：12/12 任务点、4/4 隧道、24/24 普通巡检道路，返航距起点约 3.85 厘米且实际速度归零；增加完整运行报告和轨迹证据链接。运行中按要求在直路中段随机添加 1 个障碍物，明确本次未开启障碍检测，不作为自动避障验证。

- 对比入口新增 `controllers:=both|production|contrast`，单车完整任务仅启动所选控制器、仿真和 GUI，阶段完成不再等待未参与车辆；后续规划起点使用所选车辆的实时里程计。
- 增加 Contrast 单车规划起点回归检查，并提供全部 12 个任务点、隧道、道路补漏与返航的三层运行命令。

- 入口目标改为车道中心并锁定一次行驶方向；越过捕获盒时停车请求新路线，避免在入口附近反复前后换向。
- 将 `25 mm` 斜向爬行独立配置，使用目标方向正投影计程，并限制到程后的最大延伸；转向阶段只认可朝目标减小的航向误差，平移不能伪装转向进展。
- 单元测试复用生产输出限幅、真实 `30 mm` 轴心偏移和静态车体碰撞检查，覆盖 launch 路口左右转以及停转、平移伪进展和入口越界。
- 增加 A/B 仿真专用真值检查点辅助节点：两侧均需匹配本条路线 ACK、位置接近、实际速度归零并连续保持一秒后，才授权同一超节点继续；该流程不模拟物理 RFID、位置修正或播报。

- 新增独立 `contrast_controller` ROS 2 包和同名可执行文件，链接
  `visual_navigation::waypoint_navigator_core`，完整复用正式导航的路线、健康检查、
  障碍恢复、话题和服务，只替换同 ABI 的转弯动作实现。
- 新转弯统一使用 YAML 注入的 `0.035 m/s` 实车死区线速度；`TURN_60` 和
  `TURN_30` 使用航向反馈，并将角速度限制在 YAML 配置的 `0.50` 至
  `0.65 rad/s` 区间。
- `APPROACH_ENTRY` 在前进和倒退时都修正纵向、横向和航向误差，入口位置与航向
  同时满足门限后才进入转弯；`DIAGONAL_CREEP` 同时检查位移和航向。
- 为每个运动阶段增加独立超时和无进展检查；直接调用转弯核心时暂停不消耗预算，实节点任务 hold 会复位 maneuver；超时或无实际位姿变化统一停车并返回 `NEED_REPLAN`。
- 安装双控制器对比 launch，并将其 7 项静态契约 pytest 注册到包级测试；对比双方
  共享规划路线，其他传感器、控制命令和状态话题保持隔离。
- 新增差速运动学积分测试，覆盖
  `CAPTURE -> APPROACH_ENTRY -> TURN_60 -> DIAGONAL_CREEP -> TURN_30 -> COMPLETE`
  完整链路，以及零运动触发 `NEED_REPLAN` 的失败链路。
