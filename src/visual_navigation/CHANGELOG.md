# visual_navigation Changelog

## 2026-10-07

- 完成一段路线后继续保留执行轨迹；若动态障碍把阶段终点变成死端，控制器允许任务层
  从 `GOAL_REACHED` 发起同样受限的历史回放，退回可重新规划的路口。
- 接收规划器 `z=0.002` 反向进站路口标记，从实际倒车到点姿态运行共享状态格搜索；
  修复边缘道路倒回路口后被普通正向转弯模型误判 `TURN_BLOCKED` 的问题。

## 2026-10-06

- 障碍恢复保留当前路线中恢复锚点之前的实际行驶轨迹，并新增
  `/waypoint_navigator/continue_obstacle_retreat` 服务；任务层确认当前姿态无路时可请求
  控制器分段退到更早锚点，轨迹耗尽会明确拒绝，控制器不接受外部速度或任意坐标。
- 修复扩展倒退在路口按空间最近点误选转弯前分支的问题：从实测姿态匹配历史起点，
  再按相反时间顺序回放实际限速控制命令，撤销紧路口原有的前进、倒车和转向微调；
  起点与终点均校验位置/航向，单段 30 秒超时和任务层次数上限继续限制恢复范围。

## 2026-10-04

- 从独立工作区的 `71ddfde` 快照原样引入旧原地转向控制器，构建为
  `waypoint_navigator_legacy`，供同路线、双真值底盘的闭环 A/B 仿真使用；正式
  `waypoint_navigator` 代码与入口不变，车体参数仍统一由 `vehicle_config` 注入。
- `CornerShuntController` 改为停车后异步状态格规划，不再按 0.20s 局部贪心评分；
  搜索状态包含轮轴位姿和受限线/角速度，动作包含前进、倒车、原地转向及精细恢复，
  并用整车矩形与 L 形道路缺角的 SAT 判定验证完整扫掠。
- 导出标定紧路口动作契约供 `new_map_planner` 做同模型扫掠验证；标称左右转直接使用
  已验证动作序列，约 25ms 内就绪，入口偏差或中途偏离仍回退在线状态格重规划。
- 计划执行期间每个 30Hz 控制周期复核安全；计划结束或下一步受阻时先绕过速率限制
  发布硬零速，再从实际停车姿态异步续接，消除制动惯性越过 8mm 安全边的问题。
- 启用并扩充真实姿态闭环回归，覆盖左右镜像、偏移入口、晚期切点恢复和越界失败关闭；
  正式 19 点、13.70m `layer1` 闭环已到达 `GOAL_REACHED`。
- 收紧正式 `waypoint_navigator` 的 `CornerShuntController` 出弯完成条件，
  防止在残余航向误差过大时提前切回直线寻迹并把下一路口带到内角边缘。
- 新增 `corner_shunt` 回归测试，覆盖“大残余航向不能交棒”和“受约束出弯姿态可以交棒”。

## 2026-09-16

- 根据最新实车 rosbag 修正停车路口控制：转向进度恢复保持原地对齐状态，原地精调最低角速度提高到 `0.50 rad/s`，停车拐点进站段角速度按线速度收紧。
- 将导航接收 `/imu/control` 的新鲜度窗口放宽到 `0.30 s`，匹配满负载下 BMI088 ATT 测量时间戳约 `0.21 s` 的实际延迟。

## 2026-09-15

- 更新融合健康策略相关测试：允许的 `DEGRADED_*` 状态不再携带速度缩放，定位陈旧、融合状态超时和无效位姿立即停车等待，融合 `FAULT_*` 继续锁存任务。
- 清理 README、导航代码说明和默认配置中的旧 transient localization grace / fusion speed scale 表述，明确导航只消费 `/imu/control`，D455 前向偏移为 `0.055 m`。
