# visual_navigation Changelog

## 2026-10-08

- 修复普通转弯阻尼使用上一条命令角速度的问题。转弯现在使用经过短时滤波的 IMU 实测偏航
  角速度，上一条命令仅用于输出限速和安全预测；IMU 数据失效时才回退到命令状态。
- 普通转弯越过入口线后锁存正式转弯阶段，不再因实车前后晃动重新进入入口纠偏；到达
  出口窗口后才允许最高 `0.12 rad/s` 的低速反向微调。
- 阶段衔接所需的历史轨迹倒退使用独立服务和 `ROUTE_TRANSITION_*` 状态，不再伪装成
  `OBSTACLE_BRAKING` 等障碍恢复状态。
- 路线中的 RFID 超节点到达后，导航器只沿来向低速扫描，超过配置距离后停车等待；路线
  不会因为里程计到点而自行越过 RFID 确认或执行后续转弯。任务总控须按路线号和航点序号
  调用确认服务才能放行。

## 2026-10-08

- 正常路口转弯改为实时位姿闭环：驶过 RFID 前纠正入口横向与航向误差，随后持续追踪出口
  道路目标点，同时收敛最终偏航；每个控制周期重算线、角速度，不再回放固定动作序列。
- 闭环转弯始终保持正线速度，允许根据实测偏航自动减小、保持或反向修正角速度；倒车到路口
  的障碍恢复仍使用原状态格搜索，与正常转弯解耦。
- 修复闭环初版转弯半径过大导致车头外角越界：入口转向提前到路口参考线前 15 mm，闭环
  角速度上限提高至 `0.40 rad/s`，大方位误差时保持 `0.008 m/s` 正向蠕行。每条命令发布
  前额外预测 0.2 秒整车扫掠，不安全时停车报错。
- 新增左右镜像、3 个纵向起点、3 个横向偏差和 3 个入口航向偏差的组合回归；每个 30 Hz
  控制周期再细分 5 次检查四个车角，覆盖 54 条完整转弯轨迹。
- 修复转弯期间旧道路障碍 heartbeat 抢占闭环的问题：入口方向在转过约半个计划角度前保持
  同一障碍事件锁存，不重复执行“退回路口再规划”；转向过半后仍持续阻挡时重新武装并停车，
  传感器明确 clear 后的新 true 也会正常触发。
- 障碍重规划换路线时保留之前的已行驶 breadcrumb 和命令轨迹，后续确需继续倒退时能追溯到
  更早分岔点，不再因新路线激活把恢复历史裁成路口附近几毫米。
- 路口转向期间暂停路径和普通对齐看门狗，改由转弯专用无进展监督负责；路中大方向误差
  的恢复轨迹被拒绝时发布 `FAULT_JUNCTION_RETREAT_REJECTED`。
- 删除未使用的 `wheel_track_m`、`corner_shunt_prediction_step_s`、
  `rotate_in_place_reentry_threshold` 和 `final_yaw_*` 控制参数。移除空的
  `ALIGNING_FINAL_YAW` 状态；终点位置停车后直接完成。
- `BeginJunctionRetreat()` 拒绝恢复轨迹时现在停止导航并报告
  `FAULT_JUNCTION_RETREAT_REJECTED`，不再保留旧导航状态。
- `route_editor` 的驻停请求改走 `/navigation_mission/set_motion_hold`，并识别总控映射后的
  外部来源，避免绕过任务总控直接操作导航器。

## 2026-10-07

- 收紧实际转弯控制器的道路边界余量到 `15 mm`。避障只由明确的
  `/obstacle/front_blocked=true` 事件启动，Range 仅用于距离分类。
- 任务点路线交接时保留已执行轨迹；新路段遇障退到起点仍无路时，可继续跨段倒回更早
  的分流路口，不再因路线切换清空历史而报告轨迹耗尽。
- 跨段回放起点允许最多 `0.70 rad` 航向差，并先原地对齐历史航向后回放；超过该范围
  仍拒绝执行，避免在未知位置任意旋转。
- 撤回会因模型误差反复重算、产生回摆的人控开环候选轨迹；转弯恢复为逐动作扫掠验证的
  标定状态格，保留更大的道路边界余量。
- 新增默认关闭的 `control_rate_multiplier`，仅供 loopback 快进同步提高控制回调频率；
  实车启动仍保持 `1.0`。
- 完成一段路线后继续保留执行轨迹；若动态障碍把阶段终点变成死端，控制器允许任务层
  从 `GOAL_REACHED` 发起同样受限的历史回放，退回可重新规划的路口。
- 接收规划器 `z=0.002` 反向进站路口标记，从实际倒车到点姿态运行共享状态格搜索；
  修复边缘道路倒回路口后被普通正向转弯模型误判 `TURN_BLOCKED` 的问题。

## 2026-10-06

- 障碍恢复保留当前路线中恢复锚点之前的实际行驶轨迹，并新增
  `/waypoint_navigator/continue_obstacle_retreat` 服务；任务层确认当前姿态无路时可请求
  控制器分段退到更早锚点，轨迹耗尽会明确拒绝，控制器不接受外部速度或任意坐标。
- 修复扩展倒退在路口按空间最近点误选转弯前分支的问题：从实测姿态匹配历史起点，
  再按相反时间顺序回放实际限速控制命令，撤销紧路口原有的前进、倒车和转向微调；
  起点与终点均校验位置/航向，单段 30 秒超时和任务层次数上限继续限制恢复范围。

## 2026-10-04

- 从独立工作区的 `71ddfde` 快照原样引入旧原地转向控制器，构建为
  `waypoint_navigator_legacy`，供同路线、双真值底盘的闭环 A/B 仿真使用；正式
  `waypoint_navigator` 代码与入口不变，车体参数仍统一由 `vehicle_config` 注入。
- `CornerShuntController` 改为停车后异步状态格规划，不再按 0.20s 局部贪心评分；
  搜索状态包含轮轴位姿和受限线/角速度，动作包含前进、倒车、原地转向及精细恢复，
  并用整车矩形与 L 形道路缺角的 SAT 判定验证完整扫掠。
- 导出标定紧路口动作契约供 `new_map_planner` 做同模型扫掠验证；标称左右转直接使用
  已验证动作序列，约 25ms 内就绪，入口偏差或中途偏离仍回退在线状态格重规划。
- 计划执行期间每个 30Hz 控制周期复核安全；计划结束或下一步受阻时先绕过速率限制
  发布硬零速，再从实际停车姿态异步续接，消除制动惯性越过 8mm 安全边的问题。
- 启用并扩充真实姿态闭环回归，覆盖左右镜像、偏移入口、晚期切点恢复和越界失败关闭；
  正式 19 点、13.70m `layer1` 闭环已到达 `GOAL_REACHED`。
- 收紧正式 `waypoint_navigator` 的 `CornerShuntController` 出弯完成条件，
  防止在残余航向误差过大时提前切回直线寻迹并把下一路口带到内角边缘。
- 新增 `corner_shunt` 回归测试，覆盖“大残余航向不能交棒”和“受约束出弯姿态可以交棒”。

## 2026-09-16

- 根据最新实车 rosbag 修正停车路口控制：转向进度恢复保持原地对齐状态，原地精调最低角速度提高到 `0.50 rad/s`，停车拐点进站段角速度按线速度收紧。
- 将导航接收 `/imu/control` 的新鲜度窗口放宽到 `0.30 s`，匹配满负载下 BMI088 ATT 测量时间戳约 `0.21 s` 的实际延迟。

## 2026-09-15

- 更新融合健康策略相关测试：允许的 `DEGRADED_*` 状态不再携带速度缩放，定位陈旧、融合状态超时和无效位姿立即停车等待，融合 `FAULT_*` 继续锁存任务。
- 清理 README、导航代码说明和默认配置中的旧 transient localization grace / fusion speed scale 表述，明确导航只消费 `/imu/control`，D455 前向偏移为 `0.055 m`。
