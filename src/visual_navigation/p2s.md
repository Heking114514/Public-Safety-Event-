# 转弯微调与安全门控问题方案

**记录时间：2026-10-10  |  文档状态：待审核，不修改生产代码**

## 1. 范围与基线

本文只处理 `visual_navigation` 中独立转弯动作的两个问题：

1. `TURN_FORWARD_TRIM` 与 `TURN_REVERSE_TRIM` 反复切换；
2. 弧线动作被足迹安全检查拒绝后，控制器缺少有记忆的降级处理。

本轮不修改全局规划器、RFID 任务逻辑、障碍识别、融合里程计和仿真器。当前
02:30 控制器运行版本仍是基线；生产代码必须在隔离测试通过后再替换。

## 2. 现象与根因

### 2.1 微调反复横跳（P0）

`trim_command()` 每个控制周期重新计算：

```text
target_x - current_x < 0  -> 后退
target_x - current_x >= 0 -> 前进
```

实际车辆有定位噪声、制动惯性和控制周期延迟。车辆稍微越过 `target_x` 后，误差变号，
方向立即反转。由于到位条件还同时要求横向误差和航向误差满足，纵向已经接近目标并不
能进入 `TRIM_SETTLE`，于是出现连续的前进、后退交替。

这不是障碍物事件，也不是规划器重新规划；日志中的 `+0.035 m/s` 来自微调动作本身。

### 2.2 弧线失败后的记忆不足（P1）

弧线预测出现 `footprint_outside_envelope` 后，当前流程会重置弧线控制器，回到
`TRIM_SEARCH`。虽然搜索距离和尝试计数会累计，但弧线控制参数、预测方式和动作类型
没有记录上一次失败原因，也没有进入明确的降级阶段。因此可能在新位置用相同策略再次碰到
同一种边界问题。

### 2.3 安全检查是二值硬约束（P1）

`pose_is_safe()` 对车体足迹采用 `safe / unsafe` 判定，边界内外没有连续余量分数。
这对防剐蹭是必要的，但当前没有区分“进入危险”和“恢复可行”的阈值，边界附近的预测
结果可能在两个控制周期之间翻转。

## 3. 门控策略：不增加安全门控数量

本方案**不增加新的安全门控层**，也不放宽道路边界。

保留一个唯一的几何硬安全门控：

```text
当前车体 footprint + 预测短轨迹必须在允许道路区域内，且不碰撞内角/动态障碍物
```

以下做法明确禁止：

- 删除 `footprint_outside_envelope` 检查；
- 为了通过检查而增大道路宽度或减小车体尺寸；
- 用原地旋转绕过车体扫掠检查；
- 在同一个控制回调中叠加多个互相独立的“再确认门”。

要增加的是**控制状态记忆**，不是安全门控：方向滞回、最短保持时间、稳定完成采样和
有限的失败阶段记录。这些只改变动作选择，不改变安全边界。

## 4. 修改方案

### 4.1 微调方向锁存与滞回（P0）

在转弯动作上下文中增加以下内部状态，不对外新增 ROS 接口：

- `trim_direction`：`FORWARD`、`REVERSE` 或 `NONE`；
- `trim_direction_started_at`：当前方向开始时间；
- `trim_direction_start_x`：当前方向开始时的纵向位置；
- `trim_settle_samples`：连续满足到位条件的采样数。

控制规则：

1. `TRIM_SEARCH` 选出目标后锁存方向；
2. 在最短保持时间或最小位移未达到前，即使误差变号也不换向；
3. 只有误差越过“位置容差 + 反向滞回距离”，且当前动作未满足到位条件时，才允许换向；
4. 换向前先发布一个控制周期零速，重新检查当前 footprint；
5. 纵向、横向、航向误差连续满足阈值若干周期后，才进入 `TRIM_SETTLE`；
6. `TRIM_SETTLE` 期间不再根据纵向误差选择方向。

初始参数建议（先在隔离测试中标定）：

```yaml
trim_reverse_hysteresis_m: 0.015
trim_min_direction_hold_s: 0.30
trim_min_direction_distance_m: 0.010
trim_completion_samples: 3
```

这些参数不是新的安全门。它们只防止控制输出在目标附近因噪声变号。

### 4.2 弧线失败的有界阶段记忆（P1）

保留最多 `max_trim_attempts` 的尝试上限，并为每次弧线拒绝记录：

- 失败类型：当前姿态越界、预测轨迹越界、内角碰撞或动态障碍；
- 失败时的局部位置和车辆角点；
- 本次采用的动作配置档位；
- 已搜索的回退距离。

动作配置只允许使用经过验证的有限档位：

```text
ARC_NORMAL -> ARC_CRAWL -> NEED_REPLAN
```

`ARC_CRAWL` 仍保持非零线速度不低于 `0.035 m/s`，不进入原地旋转；它可以调整已验证的
角速度/曲率范围和预测步长，但每个候选命令仍必须经过同一个几何硬安全检查。若已经在
更远的安全入口仍无法生成完整弧线，则返回 `TURN_NEED_REPLAN`，不重复使用同一参数盲试。

### 4.3 安全边界附近的滞回（P1，第二阶段）

第一阶段只实现微调方向滞回，避免把安全策略和控制抖动同时改动。

第二阶段如实验确认确有“安全/不安全”边界抖动，再为**恢复判定**增加小范围滞回：

- 进入不安全仍使用现有严格边界；
- 从不安全恢复只允许倒车/前进到明确的安全余量内；
- 不改变道路几何边界，不把边界外姿态视为可继续转弯。

该项必须有几何单测和回放数据支持后才能进入生产，不能先凭感觉放宽门控。

## 5. 状态迁移约束

```text
ARC --安全检查失败--> TRIM_SEARCH
TRIM_SEARCH --找到候选--> FORWARD_TRIM / REVERSE_TRIM
TRIM_* --稳定到位--> TRIM_SETTLE --> ENTRY_CHECK
TRIM_* --允许换向--> 零速一拍 --> 另一方向 TRIM
TRIM_SEARCH --候选耗尽或阶段耗尽--> NEED_REPLAN
```

约束：

- `FORWARD_TRIM` 和 `REVERSE_TRIM` 不得仅因单次误差变号就互换；
- `NEED_REPLAN` 不得映射成 `OBSTACLE_BRAKING`；
- 转弯动作拥有唯一速度发布权，普通路径跟踪不得同时发布命令；
- 任何非零命令都必须通过现有几何安全检查；
- 不允许恢复到旧的固定动作序列或历史速度回放。

## 6. 隔离验证计划

先只改 `TurnManeuverController` 的隔离副本和单测，生产控制器不接入：

1. 固定目标点，加入 ±5 mm 位置噪声，验证不发生高频换向；
2. 模拟车辆一次过冲，验证只在滞回距离外换向；
3. 模拟横向/航向误差未收敛，验证不会因纵向到位提前结束；
4. 模拟一次 `footprint_outside_envelope`，验证阶段记忆进入下一档而不是原参数重试；
5. 模拟所有候选失败，验证有界返回 `TURN_NEED_REPLAN`；
6. 左右转、RFID 节点和普通节点各跑一次现有回归测试；
7. 仅在单测、离线 rosbag 回放和关键仿真场景均通过后，替换生产实现并清理隔离草稿。

## 7. 验收标准

- 连续 10 秒内，微调方向不出现周期性前进/后退切换；
- 方向切换次数只在明确越过滞回距离时增加；
- 不降低现有足迹安全检查，不新增原地掉头路径；
- 弧线失败后最多进入规定的降级档位，不使用相同参数无限重试；
- 无障碍情况下不进入障碍恢复状态；
- 失败时能区分 `TURN_NEED_REPLAN` 与 `FAULT_TURN_MANEUVER`。
