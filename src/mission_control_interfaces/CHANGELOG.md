# Changelog

## 0.4.0 - 2026-10-08

- 增加 RFID 超节点确认服务，要求总控在读卡、位置校正和驻停流程完成后显式放行导航器。

## 0.3.0

- 新增 `SpeakText.srv`，让任务总控编辑播报文本并通过串口桥下发。

## 0.3.0 - 2026-10-07

- `PlanRoute` 增加连续普通路口计数输入，`RoutePlan` 返回规划后的计数状态。

## 0.2.0 - 2026-10-05

- 新增自主任务命令与持久任务状态消息。
- 新增结构化事件候选消息和带结果确认的事件播报 Action。
- 新增有界的障碍恢复继续倒退服务，用于规划器与控制器之间的多级恢复握手。

## 0.1.0

- 新增控制遥测和多来源运动驻停接口。
