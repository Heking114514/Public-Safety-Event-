# Changelog

## 2026-10-15：已知封路恢复请求

- 新增 `StartRoadRecovery`：携带已完成路线 ID、障碍版本、完整多边形与封路 ID，请求控制器停车后执行合法道路长倒车与转正；返回接受状态与恢复 ID。
- 原 `ContinueRetreat` 和 `SelectRecovery` 接口保持兼容，严格恢复仍通过候选选择确认具体动作。

## 0.4.0 - 2026-10-08

- 增加 RFID 超节点确认服务，要求总控在读卡、位置校正和驻停流程完成后显式放行导航器。

## 0.3.0

- 新增 `SpeakText.srv`，让任务总控编辑播报文本并通过串口桥下发。

## 0.3.0 - 2026-10-07

- `PlanRoute` 增加连续普通路口计数输入，`RoutePlan` 返回规划后的计数状态。

## 0.2.0 - 2026-10-05

- 新增自主任务命令与持久任务状态消息。
- 新增结构化事件候选消息和带结果确认的事件播报 Action。
- 新增有界的障碍恢复继续倒退服务，用于规划器与控制器之间的多级恢复握手。

## 0.1.0

- 新增控制遥测和多来源运动驻停接口。
## 0.2.0

- 新增 `NavigationRecoveryState`，发布控制器确认过的最后安全姿态，供任务管理器执行受控恢复规划。
