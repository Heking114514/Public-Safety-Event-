# MC02 方向联调

本轮依据用户实测修正：上一版串口正角速度使车右转，因此恢复历史角速度映射，保留正线速度映射。底盘内部正差速对应实车右转，内部两路历史名称不能直接当作车体左右。

串口映射为逻辑左通道 `v+w*b/2`、逻辑右通道 `v-w*b/2`，对应电机 ID 仍为 2/1，CAN1 不变。协议 `ENC` 按车体左右上报：车体左取逻辑右计数，车体右取逻辑左计数。上位机两路分辨率随之交换，左右距离比例仍为 `+1`。`CTL/MTR` 保持历史逻辑通道顺序，分析它们时不能套用 `ENC` 的车体轮序。

正线速度应使车前进，左右车体编码器增量和里程计线速度为正。正角速度应使车左转，里程计角速度和 BMI088 航向变化为正。ROS 串口节点继续原样发送 `linear.x` 和 `angular.z`。

直行 PID 的比例、积分、微分增益、积分限幅、输出限幅和融合结构不变。保留目标减实测的 IMU 误差，只按实车轮序配套编码器误差，并在最终差速输出处转换方向。左偏时应向右修正，倒车也按同一航向约定。

离线验证命令：

```bash
python3 scripts/verify_mc02_direction.py --firmware /路径/cup_car_mc02car
```

测试使用真实固件控制函数、真实 `ENC` 格式函数、真实轮式里程计积分器和车辆 YAML，模拟电机跟踪目标一秒，并使用用户实测确认的内部差速方向检查纠偏。它能发现命令、反馈和纠偏符号不一致；不能替代烧录后的实车验收。

本轮固件与上位机配置必须配套更新，RFID 高四位解析保持不变。

离线结果：15 组速度链路、24 组瞬时及持续偏航纠偏、4 组零误差检查通过；测试能检出旧串口转向、旧编码器轮序、旧纠偏输出与编码器误差极性。全部 `CHASSIS_YAW_HOLD` 数值与 `3f53985` 一致。ARM、ROS 包构建和轮式里程计回归通过。车辆配置相关测试 6 项通过，已知引用缺失旧包的测试未重复运行。
