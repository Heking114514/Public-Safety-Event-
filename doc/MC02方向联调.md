# MC02 方向联调

本轮固件与上位机配置需一起更新：固件标准差速映射为左轮 `v-w*b/2`、右轮 `v+w*b/2`，上位机左右 `distance_scale` 均为 `+1`。ROS 串口节点继续原样发送 `linear.x` 和 `angular.z`。

正线速度应使车前进、左右编码器增量和里程计线速度为正。正角速度应使车左转，右轮前进速度大于左轮，里程计角速度和 BMI088 航向变化为正。倒车仍按同一转向约定。航向保持误差为目标减实测，左偏时输出右转修正。

离线验证命令：

```bash
python3 scripts/verify_mc02_direction.py --firmware /路径/cup_car_mc02car
```

测试使用真实固件控制函数、真实轮式里程计积分器和当前车辆 YAML，假设电机完全跟踪目标。它能发现命令、反馈和纠偏符号不一致；不能证明电机安装方向、板内固件版本或 IMU 实际安装方向。实车联调仍需分别核对低速前进、后退、左右转时的运动与反馈。

本轮不改 CAN1、左右电机 ID 2/1、电机反向标志、控制增益和 RFID 解析。旧固件的负编码器配置不能与本轮固件混用。

验证结果：15 组直行、倒车、原地及行进转弯的命令与里程计幅值一致；12 组航向扰动及 2 组零误差检查通过。测试能检测出旧固件、新旧反馈配置混用及旧 IMU 误差符号。ARM、ROS 相关包构建和轮式里程计、RFID 回归通过。车辆配置测试有 6 项通过，1 项因引用不存在的 `pure_line_following` 包失败，修改前已复现同一失败。
