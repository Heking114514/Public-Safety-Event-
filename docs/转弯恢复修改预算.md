## 实际改动与验收

- 实现约 50 行增删，测试代码约 320 行；共 11 个文件（含预算、三份变更记录），未改任何正式 YAML 参数。
- 总控删除旧锚点等待标志；回退前仅提交已完成道路、已确认 RFID 任务，未完成路段不记完成，不伪造障碍。
- 复用 `continue_route_retreat` 与 `retreat_step_m`（当前 YAML 0.40 m），实际长度受已执行轨迹限制；没有可用轨迹直接拒绝。控制器仍执行原有停车确认、回放与有限重试。
- 同一失败仅请求一次；回放完成后才计划；完成消息早于服务响应、终止后的迟到响应均不会重新进入等待。
- 服务响应超时复用 YAML `public_service_timeout_s`（当前 2.0 s）；这是对已发请求的等待期限，不改变转弯动作判定。
